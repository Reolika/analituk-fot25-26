# Подключение Supabase

Общая база матчей с записью из админки, без коммитов файлов. Сайт остаётся статическим:
браузер читает данные по REST API Supabase, а запись разрешена только администратору.

## Шаги

1. Создайте проект на [supabase.com](https://supabase.com) (бесплатный тариф подходит).
2. Откройте **SQL Editor** и выполните файл `supabase/schema.sql`.
   Перед запуском замените `you@example.com` на свой email.
3. В разделе **Authentication → Providers** включите провайдер **Email**.
   Для простоты отключите **Confirm email** — иначе после регистрации нужно
   подтверждать почту по ссылке из письма.
4. Зарегистрируйтесь на сайте: кнопка «Войти» в шапке → вкладка «Регистрация».
   Аккаунт создаётся самостоятельно, права администратора им не выдаются.
5. В **SQL Editor** добавьте свой email в администраторы:

   ```sql
   insert into public.admins(email) values ('you@example.com')
   on conflict (email) do nothing;
   ```

   После повторного входа (или обновления страницы) в выдвижном меню появится «Админка».
6. В **Project Settings → API** скопируйте:
   - **Project URL** (вида `https://xxxx.supabase.co`);
   - **anon public** ключ.
7. Вставьте их в `config.js`:

   ```js
   const SUPABASE_URL = 'https://xxxx.supabase.co';
   const SUPABASE_ANON_KEY = 'eyJhbGciOi...';
   ```

8. Закоммитьте `config.js` и обновите GitHub Pages.

## Важно про безопасность

`anon`-ключ публичный по дизайну Supabase — он лежит в браузере у всех посетителей.
Запись защищена политиками RLS: изменять матчи может только пользователь, чей email
внесён в таблицу `public.admins`. Не используйте `service_role` ключ в браузере.

## Если ничего не настраивать

Сайт продолжит работать в локальном режиме: общие матчи берутся из `matches.js`,
личные — из `localStorage`. Вкладка «Админка» покажет, что бэкенд не настроен.

## Проверка после настройки

- Нажать на логотип → в меню войти под админским email → появится пункт «Админка».
- Добавить матч → он появится в списке и в общей истории.
- Открыть сайт в другом браузере (без входа) → матч виден, кнопки удаления нет.
